# Living World audits (2026-10-20)

Eleven read-only audits of the v4.0.2 code, one per area. The master design
(`../../specs/2026-10-20-living-world-design.md`) and the roadmap
(`../../plans/2026-10-20-living-world-roadmap.md`) are built from them, and the roadmap's item ids
(for example `A.K0`, `G.8`, `C1`, `H5`) are the work breakdown numbers in each digest's section 4.

| Letter | Area |
|---|---|
| A | World and accounting kernel |
| B | Wars, geopolitics, nations and government |
| C | Invention and research of all types |
| D | Relationships and people |
| E | News, events, dialogue and the year text |
| F | Product showcase and company events |
| G | Navigation, charts and Profit and Loss graphics |
| H | Information model (what the player knows) |
| I | Remaining special careers |
| J | Business depth benchmark and the depth rubric |
| K | Engineering, performance and test strategy |

`00-brief.md` is the brief every auditor received.
