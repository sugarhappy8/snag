# SnagWhen

**Set the price. SnagWhen waits for it.**

One wishlist across every store. Choose the price you want to pay. SnagWhen
watches Steam, GOG, Epic, PlayStation and Xbox, and tells you when it gets there.

The full product plan is in [`product-plan.txt`](product-plan.txt).

## Name and domain

The name reads like a buy rule: *"Snag Elden Ring **when** it's $25 or less."*
That is the product's limit-order idea in plain words.

- Domain: **snagwhen.com**. It was unregistered on 2026-10-02. Two public DNS
  resolvers (Google and Cloudflare) returned NXDOMAIN for its NS and SOA
  records.
- Registry premium pricing doesn't apply to `.com`, so any unregistered
  `.com` costs the registrar's normal price.
- A first year under $3 is only possible with a new-customer promo. As of
  late September 2026, the cheapest listed offer was Spaceship at $2.90 with
  the code `COMPROS`, limited to one domain per customer. It renews at about
  $10.18/yr. IONOS advertises $1 for the first year, but it renews at about
  $20/yr.
- Promo prices change often. Check the price at checkout.

Backup names whose `.com` was also unregistered when checked: SnagTime,
SnagRules, SnagOrder, WishTrigger, HoldForIt.
